Snap Sequencer

Mosaico de snapshots como secuenciador de parámetros granulares

Ocho snapshots comprimidos a 2bpp actúan como pasos de un secuenciador. Cada imagen se analiza pixel a pixel: brillo → amplitud, contraste → densidad, entropía → complejidad rítmica. Con SnapToGrains los valores se aplican al GrainEngine con transiciones suaves y una pequeña variación aleatoria en cada paso.
