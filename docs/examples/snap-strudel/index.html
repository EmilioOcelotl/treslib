Granulación + percusión rítmica mapeada desde snapshots 2bpp

La capa de percusión usa drumtraks vía Strudel; los cambios de patrón esperan al final del ciclo actual. La capa granular usa el mismo pipeline de SnapToGrains que snap-sequencer.
